# Drafting Spec 

# Admin 

## Top segment Admin 
Central image of current streamer on offer, button below that says (start draft / next player) depending on whether the draft has started. 
Previous player ( undo draft and give back coins ). Below that, a horizontal list of each streamers face with their name below it, 
their amount of coins below that (label each item) and then below that their current bid. A button at bottom to complete the draft

## Bottom segment (EXACT SAME AS PLAYER)
The Dota column of rows on each row the captains image at the start then the list of their selected teammates to the right. 
Once the draft is complete hide the top segment and only show this and add the captains final total of coins below their image

# Player
## Top Segment 
Central image of current streamer on offer, a text input box below to input the amount of coins you wish to bid ( THEY CAN INPUT AS MANY AS THEY WANT )
Below the input there is a joined pair of buttons one saying submit and one saying retract 

## Bottom segment (EXACT SAME AS ADMIN)
The Dota column of rows on each row the captains image at the start then the list of their selected teammates to the right. 
Once the draft is complete hide the top segment and only show this and add the captains final total of coins below their image

# Rules
- If nobody bids on a player then pick a random captain and deduct one coin from them ( they can go into debt TEST THIS )
- When the ADMIN clicks to start the draft or next player a 60 second timer is started, players can then bid. Once the 60 seconds is up, 
  bidding is blocked and the winner is revealed (THE NEXT PLAYER AUCTION DOES NOT START UNTIL THE Admin STARTS IT)
