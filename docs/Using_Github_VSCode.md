# How to use Githubs VSCode tool.

1. GOTO: `https://github.com/KLewin23/nuzlocke-wars`
2. You will see a small `main` in the bottom left hand corner. Click it.
3. Click `create new branch`  name it something about what you are doing (keep it short) (use dashes not spaces)
4. Press Enter and wait for the page to reload.
5. Make your changes to whatever files you want to change.
6. Go to the icon on the left panel of the VSCode window and click the icon below the search icon (it will probably have a number over it)
7. Click the small add sign on any of the files you have edited and want to change in the repo.
8. Type a message in the top box about what you changed
9. Press `Commit & Push`
